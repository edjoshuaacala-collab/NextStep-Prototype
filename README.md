# NextStep

NextStep is an internship portal designed to help JRU students find internship opportunities, submit applications, and track their application status.

## Project Structure

- `frontend/` - React and Vite frontend
- `backend/` - Laravel API backend

## Technologies

- React
- Vite
- Laravel
- MySQL
- Groq AI integration

## Setup

See the `frontend/` and `backend/` folders for their respective configuration and setup files.

## Environment Variables

Create local environment files using the provided `.env.example` templates. Never commit real API keys, passwords, or database credentials.
